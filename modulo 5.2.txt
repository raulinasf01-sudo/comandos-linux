Comandos utilizados, práctica laboratorio 5.2: Alta Disponibilidad y Clustering.

INSTALACIÓN Y CONFIGURACIÓN DEL CLÚSTER

============================================

# Utilizaremos dos servidores Rocky, uno principal y uno secundario. En ambos servidores, habilitaremos los repositorios de alta disponibilidad:

sudo dnf install -y epel-release
sudo dnf config-manager --set-enabled highavailability
sudo dnf config-manager --enable highavailability


# Luego, en ambos servidores, instalamos Pacemaker y herramientas necesarias:

sudo dnf install -y pacemaker pcs

# Habilitamos y arrancamos los servicios en ambos servidores:

sudo systemctl enable pcsd
sudo systemctl start pcsd

# Configuramos la contraseña del usuario, hacluster, en ambos servidores:

sudo passwd hacluster

# En ambos servidores, permitimos la comunicación del clúster a través del Firewall:

sudo firewall-cmd --permanent --add-service=high-availability
sudo firewall-cmd --reload

# Luego, para autenticar los nodos y hosts entre sí, desde el servidor principal ejecutamos el siguiente comando utilizando las IP addresses de los servidores utilizados (ejecutar solo en uno de los servidores):

sudo pcs cluster auth 192.168.2.131 192.168.2.132 -u hacluster
sudo pcs host auth 192.168.2.131 192.168.100.132 -u hacluster

# Tendremos que insertar la contraseña del usuario hacluster. Luego, creamos el clúster y asignamos un nombre (ejecutamos solo en un servidor):

sudo pcs cluster setup cluster-wilkan 192.168.2.131 192.168.2.132


## Práctica 3: Cluster de Alta Disponibilidad HTTP (Keepalived)

### 3.1 Configuración de Servidores Web (En AMBOS)
**Servidor 1:**
```bash
sudo dnf install httpd -y
echo "<h1>Este es el Server 1</h1>" | sudo tee /var/www/html/index.html
sudo systemctl enable --now httpd
```
**Servidor 2:**
```bash
sudo dnf install httpd -y
echo "<h1>Este es el Server 2</h1>" | sudo tee /var/www/html/index.html
sudo systemctl enable --now httpd
```

### 3.2 Implementación de HA con Keepalived
**Paso 1: Instalar Keepalived en AMBOS**
```bash
sudo dnf install keepalived -y
```
**Paso 2: Configurar Keepalived (Servidor 1 - MASTER)**
```bash
sudo nano /etc/keepalived/keepalived.conf
```
*Configuración básica:*
```conf
vrrp_instance VI_1 {
    state MASTER
    interface eth0  # Verifica el nombre de tu interfaz con 'ip a'
    virtual_router_id 51
    priority 100
    advert_int 1
    authentication { auth_type PASS; auth_pass 1111 }
    virtual_ipaddress { [IP_VIRTUAL_HTTP] }
}
```
**Paso 3: Configurar Keepalived (Servidor 2 - BACKUP)**
*Igual que el anterior pero con `state BACKUP` y `priority 90`.*

**Paso 4: Iniciar servicio y probar**
```bash
sudo systemctl enable --now keepalived
```
**Prueba:** Accede a `http://[IP_VIRTUAL_HTTP]` en tu navegador. Apaga el Server 1 y refresca; deberías ver el mensaje del Server 2.
